Gebesa Office: Aplicación de Control de Muebles Inteligentes
Desarrollé una aplicación móvil multiplataforma para Gebesa para controlar escritorios inteligentes a través de Bluetooth. La aplicación permite a los usuarios ajustar la altura, guardar posiciones de memoria y sincronizar en tiempo real entre iOS y Android.

Problema
Los escritorios inteligentes de Gebesa ofrecían funcionalidad avanzada, pero carecían de una interfaz digital para que los usuarios interactuaran con ellos. Los clientes estaban limitados a controles físicos manuales, lo que hacía que ajustar la altura del escritorio, guardar preferencias y gestionar su espacio de trabajo se sintiera anticuado y poco intuitivo. Sin una solución móvil, la experiencia del usuario no coincidía con la naturaleza innovadora del producto.

Solución
Desarrollo de Aplicaciones Bluetooth
Construí una aplicación móvil en Flutter con integración BLE para comunicarme directamente con el hardware de escritorio.

Experiencia Multiplataforma
Desarrollé una interfaz de usuario consistente y receptiva tanto para iOS como para Android utilizando una base de código compartida y paquetes BLE nativos.

Controles Personalizados y Posiciones de Memoria
Implementé una interfaz de usuario para ajustar la altura manualmente o guardar/cargar posiciones de memoria.

Integración con Firebase
Usé Firebase para notificaciones push, análisis y escalabilidad futura.

Análisis de Mercado
Pocos competidores ofrecen una integración móvil completa a nivel del consumidor.

Gebesa quería una ventaja de primer jugador con escritorios inteligentes en LATAM.

Demanda creciente de muebles ergonómicos y inteligentes en espacios de trabajo híbridos.

Resultado
Mejor experiencia del usuario: Los usuarios ahora pueden controlar sus escritorios de forma remota y guardar preferencias de altura.

Tiempo de configuración más rápido: El proceso de emparejamiento BLE se ha simplificado en todos los modelos.

Aumento del valor del producto: La aplicación añadió una capa tecnológica que diferencia a Gebesa de los competidores tradicionales.

Arquitectura a prueba de futuro: La aplicación fue diseñada para actualizaciones fáciles y expansión a nuevos modelos de escritorios o características.
